***********************************************************
Список нововведений в Trans2QuikAPI импорта транзакций версии 1.3
***********************************************************

1. Данная версия библиотеки является 64-х разрядной и с 
версиями терминалов младше 7.0.0 работать не будет (для данных версий
нужно использовать версию Trans2Quik.dll 1.2).

2. Сделаны изменения в функции обратного вызова 
TRANS2QUIK_ORDER_STATUS_CALLBACK, которая используется для получения 
информации о параметрах заявки.
2.1 Изменения в типах параметров:
	dNumber изменил тип с double на unsigned __int64.
	nBalance изменил тип с long на __int64.
	nOrderDescriptor изменил тип с long на intptr_t.
2.2 Параметр nOrderDescriptor поменял тип с long на intptr_t, у всех
специальных функций, которые вызываются из TRANS2QUIK_ORDER_STATUS_CALLBACK.
2.3 Функции TRANS2QUIK_ORDER_QTY и TRANS2QUIK_ORDER_VISIBLE_QTY
изменили тип возвращаемого значения при переводе количества
на __int64.
2.4 Для получения новых параметров заявки были добавлены новые
функции:
	TRANS2QUIK_ORDER_VALUE_ENTRY_TYPE – способ указания объема
	заявки.
	TRANS2QUIK_ORDER_EXTENDED_FLAGS – расширенные флаги заявки.
	TRANS2QUIK_ORDER_MIN_QTY – минимально допустимое количество.
	TRANS2QUIK_ORDER_EXEC_TYPE – тип исполнения заявки.
	TRANS2QUIK_ORDER_AWG_PRICE – средняя цена приобретения.
	TRANS2QUIK_ORDER_REJECT_REASON – причина отклонения заявки
	брокером.
Подробное описание приведено в п. 6.12.15 Раздела 6 Руководства
пользователя QUIK для версии терминала 7.0.0.

3. Cделаны изменения в функции обратного вызова 
TRANS2QUIK_TRADE_STATUS_CALLBACK, которая используется для получения 
информации о параметрах сделки.
3.1 Изменения в типах параметров:
	dNumber изменил тип с double на unsigned __int64.
	dOrderNum изменил тип с double на unsigned __int64.
	nQty изменил тип с long на __int64.
	nTradeDescriptor изменил тип с long на intptr_t.
3.2 Параметр nTradeDescriptor поменял тип с long на intptr_t, у всех
специальных функций, которые вызываются из
TRANS2QUIK_TRADE_STATUS_CALLBACK.
3.3 Для получения новых параметров сделки были добавлены новые
функции:
	TRANS2QUIK_TRADE_BROKER_COMMISSION – комиссия брокера.
	TRANS2QUIK_TRADE_TRANSID – TRANS_ID заявки, породившей сделку.
Подробное описание приведено в п. 6.12.16 Раздела 6 Руководства
пользователя QUIK для версии терминала 7.0.0.
4 Сделаны изменения в функции обратного вызова 
TRANS2QUIK_TRANSACTION_REPLY_CALLBACK, которая используется для получения
информации об отправленной транзакции.
4.1 Изменения в типах параметров:
	dOrderNum изменил тип с double на unsigned __int64.
4.2 Добавлен новый параметр transReplyDescriptor – дескриптор ответа
на транзакцию, который может использоваться для новых специальных
функций в теле функции обратного вызова:
	TRANS2QUIK_TRANSACTION_REPLY_CLASS_CODE - код класса.
	TRANS2QUIK_TRANSACTION_REPLY_SEC_CODE - код бумаги.
	TRANS2QUIK_TRANSACTION_REPLY_PRICE - цена сделки.
	TRANS2QUIK_TRANSACTION_REPLY_QUANTITY – количество.
	TRANS2QUIK_TRANSACTION_REPLY_BALANCE – остаток.
	TRANS2QUIK_TRANSACTION_REPLY_FIRMID - код фирмы.
	TRANS2QUIK_TRANSACTION_REPLY_ACCOUNT - торговый счет.
	TRANS2QUIK_TRANSACTION_REPLY_CLIENT_CODE - код клиента.
	TRANS2QUIK_TRANSACTION_REPLY_BROKERREF – комментарий.
	TRANS2QUIK_TRANSACTION_REPLY_EXCHANGE_CODE - биржевой номер
	заявки.
Подробное описание приведено в п. 6.12.13 Раздела 6 Руководства
пользователя QUIK для версии терминала 7.0.0.

5.Все перечисленные функции поддержаны в приложениях-примерах
  по использованию API импорта транзакций.

------------------------------------------------------
УСТАНОВКА И НАСТРОЙКА ОБНОВЛЕНИЯ
ВАЖНО: 
  Новая версия API импорта транзакций поддерживается только
  клиентским местом версии 7.0.0 и выше. Перед тем,
  как установить API импорта транзакций, убедитесь
  в том, что обновление клиентского места версии 7.0.0 или
  выше было Вами установлено. Версию клиентского места Вы
  можете увидеть в заголовке основного окна после запуска
  приложения. 

Распакуйте присланные файлы и обновите имеющеюся
версию Trans2QUIK.dll на Вашем локальном компьютере.
